# DeepSeek-V2-Lite BF16 / INT4 W4A16 对照

NVIDIA GeForce RTX 5060 Ti，PyTorch 2.8.0+cu128，CUDA 12.8。TP=1，INT4 group 64，流式加载，eager，逐专家执行。随机种子 42，4 个同时提交的请求各输入 64 个固定合成 token、输出 4 个 token，采样温度 0.8。实测为 1 次 256-row prefill 和 3 次 4-row decode。为固定批次关闭自适应配额与多步 decode。

先运行现有 Triton 框架的 Systems 采集，保存真实激活及其打包权重，再采集 Triton Compute 计数器。算子对照复用快照中的 BF16 输入、INT4 字节和 scale。整模配对在同一实例切换后端，共享权重和 MLA KV 池，回放同一组 token 与 Triton 路由结果，保留两次实际的 router 和 sampler 计算。每轮交替执行顺序。

## 启用与复现

CUDA W4A16 通过 `LLM(..., quantization="int4", int4_group_size=64, streaming_load=True, enforce_eager=True, moe_int4_backend="loop", int4_kernel_backend="cuda")` 启用。该实验以显式 `int4_kernel_backend="triton"` 作为基线。2026-11-18 起，符合条件的 DeepSeek-V2-Lite INT4 配置省略该参数时自动选 CUDA。CUDA 对小 M 使用向量化 SIMT，对其余 M 使用 Tensor Core MMA。反量化仅在 kernel 内进行，FP32 累加后输出 BF16 或 FP16。配置入口实测安装 5207 个投影并完成 4 请求各 4 token 的生成。

```bash
out=profiles/deepseek_w4a16_repro
bash benchmarks/run_deepseek_w4a16.sh baseline $out
bash benchmarks/run_deepseek_w4a16.sh ncu $out triton
bash benchmarks/run_deepseek_w4a16.sh pytest $out -q
bash benchmarks/run_deepseek_w4a16.sh operators $out
bash benchmarks/run_deepseek_w4a16.sh pair $out
bash benchmarks/run_deepseek_w4a16.sh nsys $out
bash benchmarks/run_deepseek_w4a16.sh ncu $out cuda
bash benchmarks/run_deepseek_w4a16.sh smoke $out --backend cuda
bash benchmarks/run_deepseek_w4a16.sh ncu_model $out
python3 -m benchmarks.deepseek_w4a16_report $out
```
